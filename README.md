# Mohammed Al Zllawi Portfolio

A professional personal portfolio for Mohammed Al Zllawi, built with React and Webpack.

## Overview

The site presents Mohammed's work in sales, merchant acquisition, UI/UX design, and digital project coordination. English is the default language, with an Arabic/English language toggle and full RTL support for Arabic.

## Sections

- Hero introduction
- About
- Professional experience
- Selected projects
- Skills
- Education
- Contact

## Run Locally

```bash
npm install
npm start
```

The local development server runs on:

```text
http://127.0.0.1:3002/
```

## Build

```bash
npm run build
```

The production build is created in `dist/`.

## Main Content File

Most English and Arabic text is managed in:

```text
src/data/portfolioContent.js
```
